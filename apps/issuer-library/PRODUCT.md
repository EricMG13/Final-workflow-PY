# Offline issuer research workspace

Windows credit analysts use a local browser application to discover issuer runs,
inspect dated evidence, read module outputs and final HTML reports, and prepare new
CP-OS executions. CP-OS remains the sole orchestrator. Start run is an explicit
reviewed, budgeted action; browsing never starts providers.

The user approved an integrated workspace, symbol-only branding using STT.D.svg,
the Deploy VII palette, and a more substantial working frontend. Use colour as a
signal. Historical evidence, attempts, missing data and unassessed completeness
retain their actual scope. File presence never means analytical acceptance.

Primary actions: find a run; start a new run; read Overview, Modules, Calendar, Reports or Evidence;
inspect selected findings, charts and event registers together within the selected module;
expand supporting analysis and consult Evidence & audit when traceability is needed; move between a deliverable and the module outputs it used; return with context intact.
All frontend assets are local. Enterprise file locations and the Windows launcher
remain governed by README.md and the existing platform code.
